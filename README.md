# Myntra Storefront UI

A static fashion storefront interface built with HTML and CSS. This project recreates a retail layout for learning and portfolio practice.

## Included

- Flexible header with category navigation and a labeled search field
- Promotional and category image grids
- Storefront footer layout
- Responsive grid and keyboard focus styles

## Run locally

Open `SK.html` in a modern browser. No build step is required.

## Scope

This is a visual demo. Navigation links are placeholders, and search, account actions, product data, and checkout are not connected to a backend. Brand and promotional assets are included for the interface recreation.
